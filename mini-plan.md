## ⏳ Планируемые доработки

### 1. 📝 Раздел задач
- [ ] **Редактирование задач переменным составом**:
  - Добавить возможность пользователям изменять свои задачи.
  - *Ограничение:* запретить редактирование задач за прошедшие дни (нельзя изменить вчерашние задачи и старше).

### 2. 🧳 Раздел «Увольнения»
- [ ] **Детализация времени**: Добавить поля «Время убытия» и «Время прибытия».
- [ ] **Разделение на вкладки**: Организовать отображение в виде 3 вкладок:
  1. **30 дней** (начиная с сегодняшнего дня);
  2. **Будущие увольнения**;
  3. **Прошедшие увольнения**.
- [ ] **Сортировка**: По умолчанию записи должны сортироваться по дате, начиная с ближайшей.
- [ ] **Поиск и фильтрация**: Добавить фильтры по конкретному человеку и по дате.
- [ ] **Отзыв заявки**: Добавить функционал отзыва увольнения после того, как оно уже было одобрено.

### 3. 📅 Раздел «Наряды»
- [ ] **Разделение на вкладки**: Реализовать 2 основные вкладки:
  1. **Планируемые наряды** (с возможностью детализации: *На эту неделю (основная)*, *На этот месяц*, *На следующий месяц*, *На год*);
  2. **Прошедшие наряды**.
- [ ] **UX/UI проектирование**: Продумать и реализовать наиболее удобный способ отображения и переключения между временными периодами на первой вкладке (например, с помощью суб-вкладок или выпадающего списка).
